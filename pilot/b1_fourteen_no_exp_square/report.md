# حذف میانگین مربع لگاریتم مخارج از ۱۰ مدل پنلی

۱۰ مدل پنلی بازتخمین شده‌اند؛ چهار مدل مقطعی عین نتایج قبلی باقی مانده‌اند. میانگین خودِ لگاریتم مخارج، CF جاری و میانگین آن، سایر میانگین‌ها و دامی‌ها حفظ شده‌اند. فرم درجه‌دوم QUAIDS، S&Y، قیود هسته، نمونه، قیمت و تنظیمات حل‌کننده تغییر نکرده‌اند.

از پنل تاریخی، کنترل `mean_centered_ln_expenditure_squared` و دو `mean_history_*_centered_ln_expenditure_squared`، در مجموع سه کنترل، حذف شده‌اند. این حذف شامل lambda یا جملهٔ درجه‌دوم مخارج جاری در QUAIDS نیست. RF و باقیمانده‌های آن ثابت مانده‌اند؛ شاخص‌های درآمد RF دوباره محاسبه شده‌اند.

اصلاح قبلی Bachelor/mean Bachelor فقط در مشارکت نان cohort ۱۳۹۸، سبزیجات cohort ۱۳۹۹ و نان cohort ۱۴۰۱ حفظ شده است. مقایسهٔ اثر حذف مربع با همان نسخهٔ اصلاح‌شده انجام می‌شود؛ ارقام اکسل اولیه نیز جداگانه ذخیره شده‌اند.

[اکسل به‌روز ۱۴ شیت](../b1_fourteen/paneldemand_B1_fourteen_runs.xlsx) شامل تمام ماتریس‌های ۱۲×۱۲ مارشالی و کشش‌های مخارج است. مشخصات هر شیت حذف کنترل مربع را صریحاً ثبت می‌کند. [results.json](results.json) تمام ضرایب، کنترل‌ها، ماتریس‌ها و تفاوت‌های قبل/بعد را دارد.

نسخهٔ قبل از این حذف: [اکسل تاریخی](https://github.com/sinaamiri9000-collab/paneldemand/blob/dfc9abd6c84e4326a90c1faf2490826dfc6b1796/pilot/b1_fourteen/paneldemand_B1_fourteen_runs.xlsx). گزارش و JSON بستهٔ اولیه حفظ شده‌اند.

## تفسیر و بازتولید

کشش‌ها مشتق مستقیم سهم پیش‌بینی‌شدهٔ S&Y هستند. میانگین‌های خانوار و CF در مشتق جاری ثابت‌اند. در مدل تاریخی، جدول کل میانگین با وزن تعداد مشاهدهٔ سه نقطهٔ دوره‌ای است؛ جدول‌های فرضیِ نقطهٔ مشترک همچنان ممکن است خارج از ترکیب‌های مشاهده‌شده باشند. کشش با سهم پیش‌بینی‌شدهٔ غیرمثبت «نامعتبر» نمایش داده می‌شود و عددی جایگزین آن نشده است.

وزن سال جاری فقط در RF است؛ مشارکت و IFGNLS مانند مدل قبلی غیرموزون‌اند. هیچ bootstrap یا آزمون نهاییِ معناداری اختلاف کشش اجرا نشده است.

```bash
python -m pilot.b1_fourteen_no_exp_square.run --run-all --workers 2
python -m pilot.b1_fourteen_no_exp_square.publish
python -m unittest pilot.b1_fourteen_no_exp_square.test_checks
```

کار در دو subprocess مستقل و هر کدام با یک BLAS thread انجام شده است. داده و stage/fit/logهای کاری در `intermediate/pilot_inputs/b1_fourteen_no_exp_square/` هستند و منتشر نمی‌شوند. checksum منابع قبلی و داده‌های منجمد بررسی می‌شود.
