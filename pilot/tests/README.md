# آزمون‌های صحت کد

این‌ها آزمون‌های محاسباتی جبر، مشتق‌ها و covariance هستند؛ با آزمون‌های اقتصادی ثبات ضرایب در پوشه‌های آزمایشی تفاوت دارند.

از ریشهٔ مخزن:

```bash
python -m unittest discover -s pilot/tests -p "test_*.py"
```

۲۸ آزمون عددی موفق‌اند؛ آزمون تازه حفظ میانگین‌های سه‌موجی و مقیاس‌های اصلی در نقطهٔ مرجع زیرگروه را کنترل می‌کند. اجرای آن‌ها مدل‌های روی دادهٔ خانوار را دوباره تخمین نمی‌زند.
