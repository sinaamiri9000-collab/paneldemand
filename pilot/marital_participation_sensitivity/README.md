# ۱۱. اصلاح سه معادلهٔ مشارکت

**مبنا:** سه مدل از [مجموعهٔ اولیهٔ ۱۴ اجرا](../b1_fourteen/README.md)، با میانگین لگاریتم مخارج و میانگین مربع آن. این بسته نسخهٔ قبل از حذف میانگین مربع مخارج است.

| اجرا | معادلهٔ مشارکت تغییرکرده | تغییر |
| --- | --- | --- |
| `Panel_1398` | نان و غلات | حذف `marital_Bachelor` و `mean_marital_Bachelor` |
| `Panel_1399` | سبزیجات و سیب‌زمینی | حذف همین دو متغیر |
| `Panel_1401` | نان و غلات | حذف همین دو متغیر |

حذف فقط از Probit دارای مشکل جداسازی انجام شده است؛ کنترل‌های مرحلهٔ اول مخارج و تقاضای نهفته حفظ شده‌اند. در هر اجرا، پس از اصلاح یک Probit، سیستم کامل ۱۲گروهی QUAIDS/S&Y دوباره تخمین زده شده است. نمونه، قیمت‌ها و ۱۱ معادلهٔ مشارکت دیگر ثابت مانده‌اند.

[کد](run.py) · [نتایج و مقایسهٔ قبل/بعد](results.json) · [راهنمای همهٔ بسته‌ها](../README.md). گزارش عددی این بسته به درخواست صاحب پروژه در چت ارائه شده است. این اصلاح‌ها در [حذف میانگین مربع](../b1_fourteen_no_exp_square/README.md) و [نسخهٔ فعلی بدون میانگین CF](../b1_fourteen_no_mean_cf/README.md) نیز حفظ شده‌اند.

بازتولید از ریشهٔ مخزن، با داده و اشیای مدل خصوصی بستهٔ اولیه:

```bash
python -m pilot.marital_participation_sensitivity.run --run-all --workers 2
```

cacheها در `intermediate/pilot_inputs/marital_participation_sensitivity/` نگهداری می‌شوند.
