# کد مشترک بسته‌ها

این پوشه آزمایش جداگانه‌ای نیست؛ کدهای بازاستفاده‌شده را یک‌جا نگه می‌دارد:

- `run.py`: آماده‌سازی نمونه، طراحی RF/Probit، تخمین عمومی و ابزارهای خروجی؛ entry point اختصاصی سه اجرای اول در پوشهٔ همان بسته است.
- `prices.py`: ساخت قیمت‌های بازار و Young.
- `panel_core.py`، `regime_core.py`، `plain_core.py` و `specification_core.py`: لایه‌های روی هستهٔ pyquaidsce؛ یک نسخهٔ مشترک استفاده می‌شود.
- `staged_inference.py`: covariance چندمرحله‌ای خوشهٔ خانوار.
- `frame_results.py`: کشش‌ها، مقایسهٔ اقتصادی و ابزارهای مشترک خروجی.
- `write_sensitivity.py`: renderer مشترک گزارش دو اجرای بدون سال/فصل و cohort.

واردسازی‌های کد با نام کامل package انجام می‌شوند. alias چهار ماژول کلاس قدیمی در `pilot/__init__.py` اجازه می‌دهد cacheهای pickle قبلی بدون بازتخمین خوانده شوند. دستور هر بسته در README خودش آمده است.
