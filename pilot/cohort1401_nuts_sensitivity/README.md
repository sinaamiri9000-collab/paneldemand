# ۱۲. حساسیت کشش مغزها و خشکبار در cohort ۱۴۰۱

**مبنا:** `Panel_1401` پس از [اصلاح مشارکت نان](../marital_participation_sensitivity/README.md)، با ۵٬۳۴۱ خانوار و ۱۶٬۰۲۳ مشاهده در ۱۴۰۱–۱۴۰۳. مدل مبنا در این بسته هنوز میانگین لگاریتم مخارج و میانگین مربع آن را دارد.

هر تصریح زیر **مستقل از همان مبنا** ساخته می‌شود؛ تغییرات به‌صورت زنجیره‌ای روی هم اعمال نمی‌شوند. سیستم کامل ۱۲گروهی تخمین زده می‌شود و تمرکز تحلیل بر مغزها/خشکبار/خرماست. فرم QUAIDS، S&Y، نمونه و قیمت‌ها ثابت‌اند.

| شناسهٔ اجرا | تغییر نسبت به مبنا |
| --- | --- |
| `no_exp_square` | حذف میانگین مربع لگاریتم مخارج |
| `no_exp_means` | حذف میانگین لگاریتم مخارج و میانگین مربع آن |
| `no_mean_cf` | حذف میانگین CF؛ حفظ CF جاری |
| `no_demog_means` | حذف میانگین جنسیت و تأهل؛ حفظ میانگین سن و اندازهٔ خانوار |
| `no_price_means` | حذف میانگین لگاریتم قیمت‌ها |
| `no_year` | حذف دامی‌های سال |
| `no_season` | حذف دامی‌های فصل |
| `no_time` | حذف دامی‌های سال و فصل |
| `flexible_cf` | افزودن مربع CF جاری، میانگین مربع CF و مربع میانگین CF |
| `survey_weighted` | افزودن وزن سال جاری به Probit و IFGNLS؛ مرحلهٔ اول از قبل وزن‌دار است |
| `linear_income` | حذف جملات مربع درآمد از مرحلهٔ اول؛ حفظ لگاریتم درآمد و میانگین آن |

همچنین کشش‌ها با چند روش/نقطهٔ ارزیابی محاسبه شده‌اند؛ مدل‌های مبنای قبل/بعد اصلاح مشارکت و دو برازش تجمیعی قبلی بازاستفاده شده‌اند. یک بازتخمین مبنا با نقطهٔ شروع دیگر نیز کنترل عددی است، نه تصریح تازه.

[نتایج کامل](results.json) · [کد اجرا](run.py) · [طراحی تصریح‌ها](design.py) · [محاسبهٔ کشش](evaluate.py) · [راهنمای همهٔ بسته‌ها](../README.md). گزارش عددی در چت ارائه شده است. تصریح `no_exp_square` این بسته یک حساسیت اولیه است؛ برای نسخهٔ فعلی مجموعهٔ ۱۴ مدل از [بستهٔ ۱۳](../b1_fourteen_no_exp_square/README.md) استفاده کنید.

بازتولید از ریشهٔ مخزن، با cacheهای خصوصی بسته‌های مبنا:

```bash
python -m pilot.cohort1401_nuts_sensitivity.run --fixed
python -m pilot.cohort1401_nuts_sensitivity.run --run-all --workers 2
```

cacheها در `intermediate/pilot_inputs/cohort1401_nuts_sensitivity/` هستند. اصلاح شاخص قدرت ابزار درآمد در این بسته در [راهنمای مرکزی](../README.md) توضیح داده شده است؛ ضرایب تاریخی مرحلهٔ اول تغییر نکرده‌اند.
