# وابستگی‌های سیستمی برای آرشیو Access

بازسازی خام سال ۱۴۰۲ به خواندن پایگاه Access تو‌در‌تو نیاز دارد. ابزارهای استفاده‌شده در محیط این اجرا:

- `mdbtools` و کتابخانه‌های `libmdb` نسخهٔ 1.0.1
- `7zz` نسخهٔ 26.03 برای آزمون/استخراج آرشیو
- `unrar` نسخهٔ 7.23 برای آزمون RARهای ۱۳۹۰ تا ۱۴۰۱
- درایور ODBC برای MDB و `pyodbc` نسخهٔ 5.3.0

نام بسته‌ها بین توزیع‌های لینوکس متفاوت است. نسخه‌های Python در `requirements.lock.txt` ثبت شده‌اند. فایل‌های اجرایی نصب‌شده در محیط پروژه عمداً به مخزن افزوده نمی‌شوند.
